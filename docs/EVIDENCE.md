## How the evidence was captured

```bash
JENKINS=http://localhost:8080
JOB=delivery-metrics-exporter

# console logs
curl -s -u admin:"$JENKINS_ADMIN_PASSWORD" "$JENKINS/job/$JOB/6/consoleText" > build-5-console.txt

# stage status
curl -s -u admin:"$JENKINS_ADMIN_PASSWORD" "$JENKINS/job/$JOB/6/wfapi/describe" > build-5-stages.json

# test report
curl -s -u admin:"$JENKINS_ADMIN_PASSWORD" "$JENKINS/job/$JOB/6/testReport/api/json" > build-5-testreport.json

# job configuration
curl -s -u admin:"$JENKINS_ADMIN_PASSWORD" "$JENKINS/job/$JOB/config.xml" > jenkins-job-config.xml

# artifacts from the agent workspace
docker cp jenkins-lab:/var/jenkins_home/workspace/delivery-metrics-exporter/deployment-artifact.zip .
docker cp jenkins-lab:/var/jenkins_home/workspace/delivery-metrics-exporter/deployment/output/metrics-report.json build-5-metrics-report.json
docker cp jenkins-lab:/var/jenkins_home/workspace/delivery-metrics-exporter/reports/junit-results.xml .
```
